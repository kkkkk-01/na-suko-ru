## ビーコン購入時の注意

- 「iBeacon対応・UUID/Major/Minor 設定可能（専用アプリで設定）」明記の商品を選ぶ
- CR2032 電池は別売りが多いので同時購入
- 到着後、Major/Minor をサーバー `beacons` テーブル（BCN-101 等）に合わせて設定する
  （設定手順はファームウェアと合わせてドキュメント化予定）

## 発注後の流れ

1. 発注 → 到着まで数日
2. その間にファームウェア（Arduino/PlatformIO）を開発（担当: AI）
   - Wi-Fi接続 + 30秒ハートビート（`POST /api/v1/locations/heartbeat`）
   - ボタン押下 → `POST /api/v1/calls/request`（3回リトライ + 不達可視化）
   - iBeaconスキャン（15秒ごと3秒 / 移動平均3 / ヒステリシス+6dB / -90dBm除外）
   - SoftAPプロビジョニング（SSID: NURSECALL-SETUP-xxxx）
3. 到着後：書き込み → ビーコン設定 → 実機でBLE位置検知キャリブレーション（TxPower基準値の実測）
